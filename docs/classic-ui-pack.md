RC66 adds optional static raster keys ui:quick:<exact quick slot ID>, ui:skill:<skill ID>, ui:rank:<rank number>, ui:booster:<booster code>. Existing shop:<category>:<item ID> keys already cover ordinary equipment, CPU, inventory, hangar and auction cards. Icon overrides repaint only in Classic, including when loading asynchronously, and keep the existing art on failure. This does not replace panel layouts, fonts, UI sounds, or any gameplay logic. The offline builder accepts the additional combat and UI key families. No proprietary assets are bundled.\n
