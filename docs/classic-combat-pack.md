RC65 adds optional manifest keys projectile:laser:<ammo>, projectile:laser:<ammo>:wide, projectile:rocket:<ammo>, projectile:alien:<kind>, and projectile:<family>:default. Sprites point right at frame zero. Flight textures should be static or directional; impact:<ammo-or-kind>, impact:rocket, impact:alien, impact:laser and impact:damage can use animated atlases. Additional keys: mine:armed, mine:idle, mine:default, loot:<kind>, base:<name> where safe, base:default. Map-specific backgrounds now use state.map when available. All art is optional and visual only. The existing trajectory, timings, damage, salvo counts, hit detection and fallback art remain in place. No third-party images included. Audio, UI skins and map tile layers still require future integration.\n
